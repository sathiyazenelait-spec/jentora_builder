# Jentora Builder Private Limited

A luxury architectural portal and construction management platform for **Jentora Builder Private Limited**.

## 🏗️ Tech Stack

- **Frontend**: TanStack Start / React 19 / Vite / TailwindCSS / Lucide Icons
- **Backend**: Spring Boot 3 Java (REST API, Contact Queries CRM, Super Admin Authentication)
- **Database**: H2 in-memory database / JPA Hibernate
- **Deployment Ready**: Cloudflare Workers / Nitro

## 🚀 Getting Started

### 1. Frontend Setup
```bash
cd jentora_builder
npm install
npm run dev
```
Accessible at `http://localhost:8081`

### 2. Backend Setup
```bash
cd backend
.\mvnw.cmd spring-boot:run
```
Accessible at `http://localhost:8082`

## 🔐 Super Admin Portal
- URL: `http://localhost:8081/admin`
- Manage incoming inquiries, project consultation leads, and update content in real-time.
